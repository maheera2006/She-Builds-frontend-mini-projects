# Student Registration & Result Portal

## Objective
Build a responsive portal where students can:
- Enter personal details
- Select a course
- Enter marks for different subjects
- Calculate total marks and percentage
- Automatically display Pass/Fail status
- Validate input data
- Display student details and results dynamically

## Technologies Used
- HTML5 for structure
- Bootstrap for styling and responsive layout
- CSS3 for custom enhancements
- JavaScript for validation, calculation, and DOM manipulation

## Expected Outcome
A working portal that allows student registration and result calculation with a clean UI and responsive design.
